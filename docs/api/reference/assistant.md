`POST /api/v1/conversations/{id}/actions/{actionId}/confirm` · operation id `ConfirmAction` · auth: bearer token

US-34. Saves the proposed batch in the Core API with source = assistant; 409 when expired or used.

| Parameter | In | Type | Required | Description |
|---|---|---|---|---|
| `id` | path | string (uuid) | yes | Id of the resource (UUID). |
| `actionId` | path | string (uuid) | yes | Id of the resource (UUID). |

| Status | Meaning | Body |
|---|---|---|
| 200 | OK | [ConfirmActionResponse](#model-confirmactionresponse) |
| 401 | Missing, invalid or expired bearer token | [ProblemDetails](#model-problemdetails) |
| 404 | Not found, or it belongs to another user | [ProblemDetails](#model-problemdetails) |
| 409 | Conflict with the current state (duplicate, in use, already decided) | [ProblemDetails](#model-problemdetails) |

<details><summary>Example — typical (200)</summary>

```http
POST /api/v1/conversations/7023ffdd-69d5-4ec9-9779-cc7cf0f735a8/actions/c8e1be90-68b7-4f0e-8e40-6505a2f8ab74/confirm
Authorization: Bearer <access token>
```

Response `200` `application/json`:

```json
{
  "batchId": "06f1d69d-7f51-4d44-b768-b95f5023342a"
}
```

</details>
