# Tabs

Switch between sections of one object (recipe: Ingredients · Stages · Cost · Timeline) when they do not fit side by
side. On expanded screens the same sections are shown as panels and the tabs disappear.

`.ol-tabs` (`role="tablist"`) > `.ol-tab` (`role="tab"`, `aria-selected`). Selected: `--ink`, weight 600 and a 3px
`--primary` underline (shape + weight, not colour only). Scrolls horizontally when tabs overflow; arrow keys move focus.
