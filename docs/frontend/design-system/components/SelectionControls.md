# SelectionControls

Checkbox, radio and switch with the whole label as the 44px hit area.

**Checkbox** `.ol-check > input[type=checkbox]` — optional ingredients, multi-select filters. **Radio** — one of a few
options (feeding mode). **Switch** `.ol-switch > input[type=checkbox][role=switch]` — settings that apply at once
(reminders on/off, reduce motion).

**States:** unchecked border `--border-control`; checked fill `--primary` with `--ink-on-primary` mark; focus ring
`--focus`; disabled dashed border and `--ink-muted` label. Native inputs keep keyboard and screen-reader behaviour.
