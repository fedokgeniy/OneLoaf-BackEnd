# TopBar

Sticky header with back/menu, the page title and up to two actions (search, profile). Translucent `--bg` with blur, a
hairline bottom border and `env(safe-area-inset-top)` padding for notches. On expanded screens the sidebar carries the
brand and the top bar shows only the page title and actions. Title truncates with an ellipsis; actions are 44px icon
buttons with `aria-label`.
